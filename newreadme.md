# PetKennel

Pet Kennel is a java script based program in which you click to change the emotions of one of two pets 

## Installation

You can use docker or through vite to access.

git clone (petkennel repo link)

Either within the terminal 
npm run dev
o
Or 
Docker-compose up –build
And access through there 

## Usage

You click the “Click me” button and the image of either the dog or the cat changes within the sequence of hungry->happy->angry.
